# 术语与参考资料

## 常用术语

| 术语 | 本课程中的含义 |
|---|---|
| Principal | 被识别的主体，例如当前账号 |
| Resource | 被访问的对象，例如一篇文章 |
| Permission | 操作资格，例如 article:review |
| Role | 权限的业务集合 |
| Scope | 某一操作允许的记录范围；这里不是 OAuth scope 的完整定义 |
| Policy | 作出允许或拒绝决定的规则 |
| Authentication | 认证，确认身份 |
| Authorization | 授权，决定访问是否允许 |
| Session | 服务端会话状态及请求关联机制 |
| CSRF | 利用浏览器自动携带凭据的行为发起非预期请求的一类攻击 |
| Horizontal / Vertical escalation | 水平越权 / 垂直越权 |

## 官方资料：按问题查阅

- [NIST RBAC FAQ](https://csrc.nist.gov/Projects/Role-Based-Access-Control/faqs)：角色、层级与约束的概念背景。
- [NIST ABAC 指南](https://csrc.nist.gov/pubs/sp/800/162/upd2/final)：属性访问控制的定义与设计考虑。
- [NIST DAC 定义](https://csrc.nist.gov/glossary/term/discretionary_access_control)：理解自主授权的控制权。
- [NIST MAC 定义](https://csrc.nist.gov/glossary/term/mandatory_access_control)：理解系统强制策略。
- [OWASP 授权指南](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)：按请求验证、默认拒绝及属性/关系模型的应用。
- [Spring Security 6.5 架构](https://docs.spring.io/spring-security/reference/6.5/servlet/architecture.html)：对应本项目使用的版本系列。
- [Spring Security 6.5 方法授权](https://docs.spring.io/spring-security/reference/6.5/servlet/authorization/method-security.html)：方法检查与代理机制。
- [Spring Security 6.5 CSRF](https://docs.spring.io/spring-security/reference/6.5/servlet/exploits/csrf.html)：理解接口工具中的 token 流程。
- [Spring Boot 3.5 系统要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)：选择兼容 JDK。

课程正文为面向学习者的案例讲解，不要求按顺序读完所有外部资料。实践固定 Spring Boot 3.5.14、Java 21；不要照搬其他大版本的配置而不核对。
