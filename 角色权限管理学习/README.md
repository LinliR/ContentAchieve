## 深度标准

- **重点掌握：** 能解释、独立设计并实现。
- **理解应用：** 能判断适用场景，设计简单规则。
- **建立认识：** 知道解决什么问题，与其他方案有什么区别。

RBAC 是重点，ABAC 学到能写清业务条件，ReBAC 学到能表达简单资源关系。DAC、MAC、ACL 不要求分别做一个系统。第一轮不研究通用策略引擎、图数据库或框架源码。

## 如何使用这套资料

1. 学习前，用自己的话复述上一章的一个关键概念。
2. 阅读本章的概念、案例和易错点，再完成自测。
3. 打开折叠答案核对，记录“我错在哪里”，不要只记录正确结论。
4. 在 [学习记录](练习/学习记录.md) 标记实际掌握情况。资料完成不等于你已学会。
5. 第 10 章通过后，再打开 [实践项目说明](实践项目/README.md)。

[综合练习](练习/综合练习.md) 用于复习和面试口述，[术语与资料](术语与资料.md) 用于查阅。OAuth 2.0、OIDC、单点登录、多租户、分布式授权列为后续选修。

## 贯穿案例

文章协作平台中，作者写文章，编辑审核文章，管理员维护用户与角色。文章还有部门、项目、作者和状态，因此“有审核权限”只是允许审核的一个条件。

最后你应能独立回答：**系统凭什么允许这个用户，在此时，对这份资源执行这个操作？**
